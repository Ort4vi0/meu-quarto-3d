# Meu Quarto 3D

Planejador de quarto em 3D que roda direto no navegador. Abra o site, monte o quarto e salve pela engrenagem.

Tudo fica num único arquivo (`index.html`), inclusive os modelos 3D. O quarto que você monta fica salvo no próprio navegador. Para levar para outro aparelho, use "Baixar arquivo" ou "Copiar código" no menu da engrenagem.
